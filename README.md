这个部分主要介绍 coding copilt 主题相关的论文和工作。“相关” 的概念会比较 “泛”，包括

- **商用 coding 辅助的产品**

## 关于

这里按主题归档我读过的论文。每篇笔记写清四件事：要解决的问题、方法怎么做、结果说明了什么，以及我自己的理解和疑问。

## 一篇笔记里有什么

- **问题**：这篇工作要解决的具体问题
- **方法**：核心思路和关键设计
- **结果**：主要实验结论，以及这些结论能支撑到哪一步
- **评注**：阅读时的理解、没想通的地方，以及它和相关工作的关系
